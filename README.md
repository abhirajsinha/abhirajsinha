I'm a solo founder in Hyderabad, India. I design, build, ship and run every layer of my products myself: mobile, browser, backend, AI, and the pipeline that proves the work before it ships.

## 🎧 Now building

**[Vaani](https://tryvaani.com)**, a Chrome extension that gives any webpage a voice that explains it, not just reads it.
It rewrites the page into clear spoken teaching, explains code instead of reading symbols, and speaks English, Hindi and Hinglish on demand, with the words lighting up as it goes. Understanding, not narration.

**[Vyana](https://vyanaapp.com)**, a private period tracker built for real cycles, not textbook ones. Irregular cycles first, honest predictions with confidence bands, and a report your doctor can actually read. Live on iOS and Android.

**[Omoi](https://getomoi.com)**, a private notes keeper with a biometric vault and a long term memory you can ask. Save anything in seconds, find it years later, get cited answers from your own notes.

## 🔥 Open source

**[heatwave](https://github.com/abhirajsinha/heatwave)**: a verification protocol for AI written code. Plan, build, review, prove, in a loop that never silently restarts. Separate planner, implementer and reviewer contexts, evidence over assertion. Works with Claude Code, Codex, Gemini CLI, Cursor, any agent. Zero dependencies.

**[omoi-sms-parser](https://github.com/abhirajsinha/omoi-sms-parser)**: on device parser for Indian bank and UPI transaction SMS. A DLT sender ID gate plus a deterministic grammar, so it generalises to banks it has never seen. Pure TypeScript, zero dependencies.

## 🧭 How I work

- **Ship one thing, then the next.** Build one, ship one, branch off the released trunk.
- **Evidence, not assertion.** Nothing is "verified" without a method and an artifact. That rule became [heatwave](https://github.com/abhirajsinha/heatwave).
- **Fix the class, not the instance.** If a fix only holds for the bug I saw, it is not a fix.
- **AI agents as teammates, not autocomplete.** Separate planner, implementer, reviewer. Nobody grades their own homework.
